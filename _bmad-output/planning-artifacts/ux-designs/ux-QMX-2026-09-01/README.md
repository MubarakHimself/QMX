Use these evidence labels in working material:

- **Confirmed intent:** explicitly stated/accepted by the operator.
- **Documented basis:** supported by a named existing decision or contract; not proof of implementation.
- **Verified implementation:** demonstrated in the actual implementation/runtime, with evidence.
- **Proposal:** a suggested design/adaptation, not yet accepted.
- **Open:** unresolved; do not fill with an assumption disguised as a fact.

A UI **world** is an opened work environment. Backend `world` refers to live/replay/simulated evidence semantics. They are not the same taxonomy. Department membership is not permission to bypass data access rules.
