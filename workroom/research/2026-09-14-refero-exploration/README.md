## Strongest design findings

1. **Give the working object enough room.** Rork and Manus demonstrate agent conversation adjacent to files and output. Pryzm and Equals demonstrate substantial direct tool use. QMX should let the active notebook, comparison, strategy or Book occupy the space its work requires. A permanent narrow result pane is insufficient.
2. **Selections should drive useful tools.** fal's multi-selection reveals bulk actions and a selection summary. W&B retains run identities beside charts. Candidate QMX behavior: select three strategy variants, see their comparison and offer batch operations without losing the collection. These behaviors are proposed, not verified backend contracts.
3. **Separate destinations from open work.** Linear groups product destinations while local toolbars control the current view; Missive exposes secondary actions in a menu. A possible QMX arrangement is compact global entry, durable open-work tabs, and one contextual navigator. The identity of a tab—undertaking, department or object—remains open.
4. **Evidence can sit beside reasoning.** Matter pairs source text and highlights. ChatGPT iOS separates activity and sources in a sheet. Candidate QMX behavior: inspect a claim's supporting run, dataset or source beside the current work, and pin it when sustained comparison is needed.
5. **Activity deserves an attention model.** Linear's mobile inbox pairs events with objects and actors. Exa exposes run state independently of conversation. A QMX attention view could show completed, blocked or review-ready work across environments. Routine tool logs belong behind that summary.
6. **Dense and calm are task states.** Kraken's terminal gives simultaneous instruments room; Glassnode compresses metrics into rows; Matter is comfortable for reading. QMX need not maintain one density or one pane arrangement for every activity.

## Three arrangements to explore, not alternatives to approve yet

### Shared workbench

A durable open undertaking contains a substantial agent session alongside independently usable documents, notebooks, tables or tools. Either can expand. A navigator identifies related material. Best for open-ended research and Python/strategy development. Main risk: conversation, files, logs and tools all becoming permanent columns. Require an explicit focus action and a reliable return to the previous arrangement.

### Comparison bench

Candidate/run selection feeds a broad comparison area. A temporary inspector shows exact configuration, lineage or evidence for the selected item. Agent conversation can join the comparison when useful. Best for optimization, robustness, What-if and portfolio composition. Main risk: becoming a table of unexplained metrics; keep dataset, period, assumptions and version identity close to comparisons.

### Tool canvas

The strategy, portfolio composition or procedure is the primary working surface. Available components live in a library; selected items reveal relevant controls. Agents help create, explain and revise the same material. Best when direct manipulation is meaningful. Main risk: implying a compulsory visual builder or universal experiment graph; ordinary Python must remain a first-class alternative.

These may be arrangements within a shared environment rather than separate products. That relationship needs discussion and a later interaction study.

## Additional creative hypotheses

- A comparison shelf holds selected variants while browsing elsewhere, then opens a full comparison without recreating selection.
- A reference can be opened temporarily beside the active work and pinned only when useful.
- An agent can hand over an editable result surface with provenance; discussion and direct manipulation remain linked.
- Save a working arrangement together with selected objects, filters and open evidence, so resuming restores intellectual context as well as pane positions.
- A context summary makes explicit which files, versions and datasets an agent is using; selection on screen should not silently expand agent authority.
- A compact activity strip can open an attention inbox. Completion events should link directly to usable output.
- Library collections can have both visual summaries and dense tables; presentation should follow the objects and comparison task.
- Use the iOS examples to learn progressive disclosure and concise attention design. They do not establish a mobile QMX scope.
