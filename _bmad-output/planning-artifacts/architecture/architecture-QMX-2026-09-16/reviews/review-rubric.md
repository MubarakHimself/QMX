#### H-1 — AD-17 `originating_research_ref` is two legal objects; brownfield already demands one encoding

**Where:** AD-17 Rule (“QML-local `research_ref` **or** a Knowledge Citation digest — never the new Bot `fp1`”); AD-21 (`research_ref` is not a qmf-registry `fp1`); AD-7 origin triple on StrategyHandle; `qml.conformance.registration.graduate_to_governed` @ `integration@8510c03`; FR-RES-11/12.

**Two conforming units**

- **Unit A — hypothesis-lineage epic.** Graduation always passes `originating_research_ref = research_ref` (content hash of Stage 0 semantic content + format version). Seed cites stay on AD-7 `origin: { source_ref, snapshot_ref, locator }` (non-`fp1` StrategyHandle field). Don’t-box-in skip of Stage 0 still requires minting a hypothesis (or hashing the ungoverned logic source-manifest with the same helper) before `graduate_to_governed`.
- **Unit B — cite-digest epic.** Reads the “or” literally. Graduation may pass the Knowledge Citation’s cite-copy digest and skip Stage 0 types entirely. `research_ref` is a QML-only display id. AD-21’s “not `fp1`” is read as a *different string scheme* (`research:sha256:…` or a raw hex digest). `graduate_to_governed` is wrapped or forked because `_coerce_fingerprint` already refuses anything that is not `fp1:sha256:<hex>`.

Both obey the written Rule. What diverges: the CT-07 `promoted-from` target, whether a graduated bot can be traced to a hypothesis, whether skip-Stage-0 graduation is legal, and whether Stage 0 identity is the same type the helper already consumes.

This is the mill’s load-bearing bridge. QL-8 already said graduation links “its originating **research artifact**.” The restart’s job was to say what that artifact is now that Stage 0 exists. “Or” leaves two graphs.

Brownfield: `graduate_to_governed` coerces `originating_research_ref` through `Fingerprint.try_create` and errors “a Bot citation or research artifact is referenced by `fp1:sha256:<hex>`”. That encoding is qmf-core’s content-hash spelling (CT-05), **not** “this is a Workbench AD-3 Library object.” AD-21’s “not a qmf-registry `fp1`” is the right *kind* law and the wrong *encoding* implication.

**Action:** autofix. Replace the AD-17 parenthetical with a closed set:

1. Encoding is qmf-core `Fingerprint` (`fp1:sha256:<hex>`). “Not `fp1`” means **not a qmf-registry kind / not a Library object**, never a second hash scheme.
2. Graduation from Stage 0: `originating_research_ref` **is** the hypothesis `research_ref` (AD-21). Distinct from the new Bot `fp1`. Self-edge remains refused.
3. Knowledge Citation digest / cite-copy `artifact_ref` is **not** a legal `originating_research_ref`. It remains AD-7 `origin` metadata only.
4. Don’t-box-in: tunnel entry still requires no Stage 0. If/when that Python later graduates, the host supplies a Fingerprint of the originating research bytes it actually has (typically the logic source-manifest). It must not invent a hypothesis and must not point at a seed cite-copy to fake one.
