## 4. Non-negotiable vocabulary and posture

- **Name of the system.** "The QMX agentic system" = daemon + QMA SDK + wire contract. **QMA = QuantMind Agents, the SDK only** — never the name of the whole system, never a framework. Python namespace `qma.*` (`qma.core`, `qma.wire`, `qma.daemon`); **no blanket `qmx.` prefix anywhere**. In prose "the QMX agentic system (QMA)" where unambiguous.
- **Quant**, never Bot and never Steward, for the persistent named organizational actor. `ActorId` = `quant:<desk_slug>/<quant_slug>`. The five `desk_slug` values are `research`, `trading`, `dev`, `analysis`, `pm`. The five **Desks** are Research, Trading, Development, Analysis, PM; the five **Roles** are Researcher, Trader, Developer, Analyst, Product Manager — a Role name never names a Desk; "quant" is never an adjective.
- **Graph Template** (authored, stateless, plugin-contributed) vs **Task Graph** (daemon runtime state) — never interchanged. **Loop** is a node kind inside a Graph Template. **Skill** ≠ Loop.
- **Task Ledger / Quant Ledger / Experiment Ledger** are the three stores; a **desk ledger view** is a read-time index; the **event journal** is neither a ledger nor telemetry. "QMX Event Ledger" is a retired name for the event journal.
- **admit / apply / promote** — three verbs, three acts: memory candidates are admitted (`admission_confidence`), RefinementProposals are applied out of the staging store, and only a registered artifact is promoted into the live zone by a human OUTSIDE QMA (L17). "promote"/"promotion" never appears for memory or refinement.
