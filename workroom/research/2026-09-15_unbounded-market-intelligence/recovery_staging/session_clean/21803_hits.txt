156: - Simplicity: Global variables are managed directly by the MetaTrader terminal. No need to handle the file paths, permission issues, or custom serialization formats.
157: - Speed: Reading and writing to global variables is significantly faster than file I/O, which is important because we perform these operations only during state transition (once per news window), but still we want minimal overhead.
158: - Automatic synchronization: The terminal ensures global variables are saved to disk automatically and survive a restart. With files, you must manually manage flushing, closing handles, and reopening after a restart.
159: - No external dependencies: The code remains self-contained.
