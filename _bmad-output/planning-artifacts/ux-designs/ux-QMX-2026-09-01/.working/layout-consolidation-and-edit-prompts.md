## Rendering references: evaluated, not adopted

[shadcn/ui](https://ui.shadcn.com/docs) provides editable component code and composition primitives. It can implement a chosen layout but does not decide QMX's navigation.

[JSON Render](https://json-render.dev/docs) renders specs through a defined component/action catalog. Its [shadcn package](https://json-render.dev/docs/api/shadcn) supplies components and permits custom additions; its [MCP package](https://json-render.dev/docs/api/mcp) supports serving interactive MCP Apps. This creates a plausible link to the previous extension discussion. Proposed boundary: QMX owns stable navigation and context; catalog-constrained content can vary inside allowed tool surfaces.
