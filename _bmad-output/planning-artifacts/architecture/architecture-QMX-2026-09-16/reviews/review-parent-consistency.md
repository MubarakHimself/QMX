#### F-1 — ADOPTED AD-6 / AD-8 name the two proposed parent amendments as current owners

**Where:** AD-6 `[ADOPTED]` “QML Stage 0 hypothesis”; AD-8 `[ADOPTED]` “COMP-QML (Stage 0 types + Stage 1 authoring + QL-7/QL-8)” and “COMP-QMA-WIRE (federated hit DTO / additive CT-40 family only)”; Structural Seed `qml/src/qml/research/  # NEW Stage 0 types`; Capability map “Hypothesis authoring | qml.research | AD-15”.

**Parents:** QL-1 surface count is still three until amended. Workbench AD-3 query surfaces are still the three named Artifact/ledger surfaces; federation is proposed commentary only.

**What:** AD-15 / AD-1 / AD-9 correctly stay `[PROPOSAL]`. ADOPTED owner rows do not. Two units can both “obey”:

- Unit A waits for the operator to accept the QL-1 / Workbench AD-3 commentary amendments, and ships only seed bind + informal notes.
- Unit B reads AD-8 ADOPTED and ships `qml.research` format-versioned types plus a CT-40 federated Library search as current law.

That is how a proposal becomes a silent parent override in the factory, without anyone editing QL-1 or Workbench AD-3.

**Action:** apply. In AD-8 (and the AD-6 plane-1 sentence): Stage 0 **process** (cite → structured hypothesis → graduate) is adopted as QML-owned work. Stage 0 **types on QML’s format-version ladder** remain AD-15 `[PROPOSAL]` pending the QL-1 count amendment — do not call them parent-legal “helpers under (1)”. #### F-2 — AD-4 include/exclude + `plain_file.py` can hardcode Stats layout into `qma-core` (QMA AD-19)

**Where:** AD-4 Rule include/exclude lists; Structural Seed `qma-daemon/.../plain_file.py  # extend snapshot include/exclude (AD-4)`; AD-5 “`qma-core` stays layout-agnostic; path/heading conventions live in the research-corpus adapter.”

**Action:** apply. AD-4: include/exclude is **research-corpus / this `source_id` adapter config**, not `qma-core` `PlainFileLibrarySource` defaults. Structural Seed: snapshot set lives on the desk pack bind, not as a Stats-shaped patch to `plain_file.py` (that file may grow a config hook only).
