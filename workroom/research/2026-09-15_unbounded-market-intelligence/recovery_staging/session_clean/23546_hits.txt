112: ### Understanding the News Offered in MQL5
114: It is important to understand the [three structures](https://www.mql5.com/en/docs/constants/structures/mqlcalendar#mqlcalendarvalue) used by the MetaTrader5 economic calendar API, as we will be building a custom structure for the news shortly.
126: - id – A unique identifier for the country.
127: - name – The country's name, such as United States or Japan.
128: - code – The two-letter country code, such as US or JP.
129: - currency – The country's currency code, such as USD, EUR, or JPY.
130: - currency\_symbol – The currency symbol, such as $ or ¥.
131: - url\_name – The country name used in the mql5.com website URL.
137: - id – A unique identifier for the event.
138: - name – The name of the economic event.
139: - country\_id – The identifier of a country associated with the event.
140: - [importance](https://www.mql5.com/en/docs/constants/structures/mqlcalendar#enum_calendar_event_importance) – Event's importance (Low, Medium, or High).
141: - [frequency](https://www.mql5.com/en/docs/constants/structures/mqlcalendar#enum_calendar_event_frequency) – How often the event is released (monthly, quarterly, yearly, etc.).
142: - [sector](https://www.mql5.com/en/docs/constants/structures/mqlcalendar#enum_calendar_event_sector) – The part of the economy the event belongs to, such as Trading, Government, consumption, etc.
143: - [time\_mode](https://www.mql5.com/en/docs/constants/structures/mqlcalendar#enum_calendar_event_timemode) – Specifies how the event release time is provided (exact time, all-day, no time, etc.)
144: - [unit](https://www.mql5.com/en/docs/constants/structures/mqlcalendar#enum_calendar_event_unit) – The unit used to measure the reported value, such as percent or currency.
145: - digits – The number of decimal places used when displaying values.
146: - source\_url – The website where the data is officially published.
147: - event\_code – A short code that uniquely identifies the event.
151: While MqlCalendarEvent describes what the event is, MqlCalendarValue stores the results of a particular release. For example, the U.S Consumer Price Index (CPI) is released every month. The event remains the same, but every month has its own set of values.
155: - time – The date and time when the news was released.
156: - period – The reporting period the data refers to.
157: - actual\_value – The value that was actually reported.
158: - forecast\_value – The value economists expected before the release.
159: - prev\_value – The value reported in the previous release.
160: - revised\_prev\_value – The corrected previous value if it was revised later.
161: - revision – The revision number for that release.
162: - impact\_type – The expected effect of the news on the currency.
168: 1. *MqlCalendarCountry represents a country a news  event and its values belongs to.*
169: 2. *MqlCalendarEvent represents an economic event being announced.*
170: 3. *MqlCalendarValue shows the results of a particular news release.*

811: ### Backtesting News-based Programs in the Strategy Tester
813: One limitation of the built-in Economic Calendar is that its functions aren't working in the strategy tester, i.e., they throw errors during backtesting. Functions such as CalendarValueHistory(), CalendarValueLast(), and other calendar-related APIs rely on live calendar data provided by the terminal. As a result, these functions either fail or return no data when executed inside the strategy teste
815: This presents a challenge when developing Expert Advisors (EAs) that depend on economic news. While the trading logic can be tested, any functionality that relies on the Economic Calendar cannot, making it impossible to accurately evaluate news-based strategies during historical simulations.
817: A common solution is to export the required economic calendar data to a CSV file while the program is running on a live or demo account. During backtesting, the Expert Advisor can then load the same data from the CSV file instead of querying the built-in calendar. This allows the program to behave consistently in both live trading and the Strategy Tester while using identical news data.
821: ```
822: #define NEWS_CSV "news.csv"
823: #property tester_file NEWS_CSV
825: #include <Bootstrap\News\provider_csv.mqh>
899: ```
