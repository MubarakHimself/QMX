# ADR-0024: QMX Workflows construction kit — composition over existing applications

Date: 2026-09-19. Status: accepted (docs authority only).

## Context

QMX already has five application-layer products on the QMF toolbox: `COMP-QMB` (experimentation library + `qmb` CLI), `COMP-QML` (bot authoring / research mill), `COMP-QMN` (trading node, paper then live), and `COMP-QMA-CORE` / `COMP-QMA-WIRE` / `COMP-QMA-DAEMON` (agentic system). The 2026-09-18/19 architecture sitting produced a feature-altitude spine (`architecture-QMX-2026-09-18/ARCHITECTURE-SPINE.md`, candidate `qmx-workflows-arch-2026-09-19-c`, local AD-1..AD-31) so those products compose as one **Workflows construction kit**: capability / extension / workflow / mini-app / widget, with session-aware QuantMind/QMX Copilot, Artifact Library discovery, app orchestration, data recipes, Alternative Trading Composition honesty, and future UI-host contracts. Parents QMF, QMB B-1..15, QML QL-1..10, NODE TN-1..25, QMA AD-1..29, CONNECT AD-1..5, Workbench AD-1..16, and the mill package bind read-only. Local `AD-1`..`AD-31` do not renumber those parents (DEC-0445).

Planning checkout is `main`. Implementation was inspected on `integration@270e992995c2378ca63cf6343254ef8140a8c97e` without switching branches. At that SHA federated discovery is still `KnowledgeHit|ArtifactHit` only; `ContributionHit` is not on the wire; `product_session` is absent; TaskGraph classes exist but the store is in-memory with edges dropped and outbox absent; Operation descriptor / InvocationEnvelope / GrantRecord are absent; `AlternativeRunConfig` / `PolicyPair` are not in code; QML→QMB→QMN cross-component integration is unsupported (P2-INT-001). Class/test existence is not end-to-end proof (DEC-0286, DEC-0450). Do not use `8510c03` for absence claims (DEC-0450).

OD-01 is closed. Focused Codex recheck of AD-23..AD-31 **ran** 2026-09-19 (`CODEX-RECHECK-RETURN-2026-09-19.zip`, SHA-256 `aa64bc8a431d543d86da77b182b2c18e449d3a6665fe837709902dc95b3adeb4`). ## Options considered

1. **Mint a sixth application (`COMP-WF` / `COMP-LIB` / extra experiment daemon / extra identity store)** — a permanent process besides `qma-daemon`, `qmn`, and QMB process-per-run children. Rejected because: QMF stays the one framework (L7/L8); every new capability names an existing `COMP-*` owner or an explicit connect/extend of one (DEC-0414, DEC-0446, DEC-0451). DEC-0084 stays dead.
2. **Dummy Book / BMS path** — mint identity / no-op / unlimited / pass-through / sentinel fps (`NULL_BOOK`, empty-object Book, fake MIS) so a second composition can pretend to satisfy L36. Rejected because: dummy is `INVALID_INPUT` at compile, register, validate, simulate, and seat; Book/BMS are the default implementations of accounting and risk/sizing roles, not a ceiling that requires fake records (DEC-0424, DEC-0436, DEC-0448).
3. **Treat sensing / research / `UngovernedWorkConfig` as a complete second trading system** — call data-ML or sensing-only a seat or an Alternative Trading Composition. Rejected because: sensing-only is not a seat and is not ATC; ATC requires a complete `PolicyPair` under `AlternativeRunConfig` with Book/BMS/bot keys absent, not null (DEC-0424, DEC-0436, DEC-0451).
4. **Invent a JobHandle dialect with `succeeded` / `awaiting_approval`** — drift from QMA AD-17 vocabulary. Rejected because: JobHandle reuses QMA AD-17 exactly (`queued` \| `running` \| `done` \| `failed` \| `cancelled` \| `aborted` \| `unknown`); `awaiting_approval` is a Mission/Task gate, not a JobHandle state (DEC-0439).
5. **Reuse the existing applications and connect what already exists** — chosen. Workflows is composition, descriptors, sessions, and procedures over QMF, QMB, QML, QMA, and QMN with no new COMP and no new CT (DEC-0445, DEC-0446).

## Decision

The Workflows spine AD-1..AD-31 is adopted in full as DEC-0414 through DEC-0444. The umbrella is DEC-0445. Architecture-preflight is DEC-0446. Cheap-veto assumptions ride DEC-0447. L36 named amendment is DEC-0448. DEC-0389 two-class freeze is named-amended by DEC-0449. Wiring honesty at `270e992` is DEC-0450. Dead-list honors are DEC-0451.

- **AD-1 / DEC-0414 — construction kit is composition, not a sixth application.** Every new capability names an existing `COMP-*` owner or an explicit connect/extend of one. Minting a new application package or a permanent process besides `qma-daemon`, `qmn`, and QMB process-per-run children is a spine amendment. QMF stays toolbox (L7/L8). “Under QMF” never means one process or one database.
- **AD-2 / DEC-0415 — four discovery rails; Artifact Library kinds unchanged.** Product discovery concatenates typed hits and is never a fourth store and never a door run. The four rails are: (1) `KnowledgeHit`, (2) `ArtifactHit`, (3) `ContributionHit` (live `published_contributions()` tuple; never fp1, never a registry kind, never `ArtifactHit.kind`), and (4) hypothesis listing on `qml.research` / `research_ref`, which is **refused on the facade** and is not a fourth `hit_class`. Pins store `(qualified_id, package_version, availability_revision)`. Occupancy none. Daemon never `import qmb`. DTO owner is `COMP-QMA-WIRE` (additive CT-40 family, no new CT number). Query owner remains `COMP-QMA-DAEMON` `published_contributions()`. Additive CT-40 family is **usage annotation and prose specification** until FEAT-0051 lands a format mint of CT-40 fields; do not mint CT-52 (DEC-0446, GAP-0094).
- **AD-3 / DEC-0416 — Capability Operation Interface is the shared contract.** Every public operation publishes a versioned descriptor (stable id, owner COMP, input schema, output shape `value` \| `artifact_ref` \| `job_handle` \| `event` \| `stream`, cardinality, empty_policy, effect class, lifecycle verbs). Collection mapping lives on Graph Template edges (AD-5), not on the descriptor. Every public call carries an `InvocationEnvelope` (AD-24). Manifests request; the host grants structured GrantRecords. The only parameter authority is `input_schema`.
- **AD-4 / DEC-0417 — four workflow layers stay distinct.** (1) Experimentation Board layout is client-only and writes nothing. (2) Graph Template is an authored, versioned, stateless DAG with compile identity `(qualified_id, version)`. (3) Task Graph is one Mission’s execution projection; persist `edges: {from, to, mapping}` and walk successors. (4) Ungoverned library call writes no Mission. A Stage 0 `graph` is none of these and is never compiled to a bot, Graph Template, or `run_slice`.
- **AD-5 / DEC-0418 — mapping is explicit; no silent Cartesian.** Each port declares kind `reference` \| `data` \| `event` \| `control`. Collection mapping on the edge is `one` \| `zip` \| `broadcast` \| `keyed-join` \| `cartesian`; Cartesian requires an explicit flag. Join algebra is AD-26. Conditional skip is a node kind, not dropped edges.
- **AD-6 / DEC-0419 — Graph Template topology is a DAG.** Registration refuses self-loops and any directed cycle. Pairwise reverse-edge checks are insufficient. Runtime Loops remain node state, not template cycles.
- **AD-7 / DEC-0420 — reuse QMA as the procedure runtime; extend in place.** Author in Graph Templates; instantiate via Mission Compiler; schedule via RoutineScheduler; place QMB work via `place_procedure_step`. ExperimentSpec successors are lineage, not control-flow edges — CT-07 MUST NOT be walked as graph successors. Persist `task_graph_state` including edges in daemon sqlite (existing named projection). Occupancy is `environment_lease` + Workbench AD-8 door law, not a separate table. Skills remain knowledge; they never compile to Missions and never grant tools.
- **AD-8 / DEC-0421 — product sessions are authority overlays, not QMA Session.** `product_session` is a journal-projected record kind with ids `psess:`; QMA Session ids remain `sess:`. Cardinality is 1 product_session → many QMA Sessions. `ProductSessionProfile` is the closed immutable enum `{authoring, app-use}`. Sessions own context and grants; tabs do not. App-use may mint a `change_request` staging kind and must not edit package source, install code, elevate grants, or retarget accounts. Specialists remain.
- **AD-9 / DEC-0422 — Copilot discovers granted descriptors; prose is not authorization.** Tool availability = intersection of published ContributionHits, host grants, `product_session` GrantRecords, and health. Skills describe behavior; they do not grant. A model-authored hook cannot override a failed deterministic check or privilege gate.
- **AD-10 / DEC-0423 — four cross-app composition modes.** Supported modes, none compulsory: consume saved artifact by fp1; invoke exported operation through AD-3; coordinate via Graph Template; composite app as an instance graph (not a Library kind). Nested invocation does not union permissions. Composite authority is the host-granted intersection.
- **AD-11 / DEC-0424 — default Book/BMS is not a ceiling; dummy Book is forbidden.** Dummy (identity / no-op / unlimited / pass-through / sentinel fps) is `INVALID_INPUT`. Three config types: `ResolvedRunConfig` (Book/BMS/bot required — default path); `AlternativeRunConfig` (those keys absent, not null — complete ATC via AD-23); `UngovernedWorkConfig` (those keys absent — ungoverned / data-ML / sensing-only, not a seat and not ATC). When ATC is selected, QML, QMB, optional MIS, QMN, paper, and live adopt it.
- **AD-12 / DEC-0425 — data recipes wrap qmf-data; provider ≠ venue.** Recipe definition identity is `(recipe_def_id, recipe_def_version, recipe_def_hash)` (AD-31); output identity is release fp1 plus CT-07 lineage (COMP-QMB wrap of COMP-QMF-DATA). Not a Library kind. CT-06 recipe kind stays deferred. Provider ≠ venue ≠ account ≠ instrument.
- **AD-13 / DEC-0426 — identities stay separate.** Semantic identity is fp1 (artifacts), `research_ref` (hypotheses), `(qualified_id, package_version)` (contributions — not fp1), ExperimentSpec fp1, `composition_fp`, `instance_id`. Display names and Board layouts are UX. Pack states stay distinct: installed ≠ enabled/activated ≠ session-granted.
- **AD-14 / DEC-0427 — sequential handover; software rollback cannot undo fills.** Default replacement is develop → evaluate → non-real-money validate → explicit activation after stopped/flat-or-drained handover via the AD-25 fencing machine. Outstanding positions, UNKNOWN commands, and shared-account concurrency are separate refusal/drain cases. Software rollback never reverses fills. GAP-0058 stays its own increment.
- **AD-15 / DEC-0428 — compute placement is preflight, not a toggle sticker.** States are distinct: available / configured / authorized / reachable / healthy. Training ≠ inference ≠ trading deployment. Bind only through existing QMA ExecutionEnvironment / ComputeProvider ports. Browser/computer-use remain fail-closed until registered (GAP-0070/0078).
- **AD-16 / DEC-0429 — persistence owners stay split; new product records are not qmf-core.** Evidence stays in qmf-data rooms, CT-13 journals, registry sqlite, and QMB JSONL (including ATC rows tagged `composition_class: alternative`). v1 daemon additions (complete list): `product_session` journal projection; durable `task_graph_state` including AD-26 outbox; mini-app instance rows in existing plugin-install projection; GrantRecord rows beside product_session. No other new sqlite.
- **AD-17 / DEC-0430 — UI host contracts now; chrome is GAP-0081.** The host is a client of qma-wire, QMB API/CLI, and QMN three doors. Contribution descriptors are wire-owned DTOs — not a v1 `ui_view` plugin point until a named GAP-0081 increment. JSON Render and MCP Apps are presentation adapters, not identity, persistence, runtime, or authority. Do not pin `@json-render/*` in this sitting. QMB remains the only operator CLI.
- **AD-18 / DEC-0431 — packages export without private lineage or secrets.** A pack is versioned (manifest, contribution list, requested capabilities, compatibility, migrations). Lifecycle is AD-30. Missing dependency is a hard error at enable. `exports_secrets: false` is a request; an independent export scanner is the oracle. Marketplace stays dead (DEC-0361).
- **AD-19 / DEC-0432 — mutation testing is a test-strength principle.** Behaviour oracles (BDD/journeys) come first. mutmut is optional, WSL/POSIX on Windows, disposable copies only, never `mutmut apply` on the shared worktree. Mutation score is not architecture proof.
- **AD-20 / DEC-0433 — defaults and templates ship with a custom path.** Ship enough defaults that real work is possible. Graph editing is not the only programming route (L9).
- **AD-21 / DEC-0434 — headless parity of operations.** Deep behaviour of an AD-3 operation is identical across that operation’s supported doors. Unsupported door → typed `unsupported_door`, never a newly minted `qma`/`qmn` CLI.
- **AD-22 / DEC-0435 — Portfolio Manager is a label, not an identity rewrite.** Trading-floor Role display becomes Portfolio Manager. Keep `desk_slug=pm` until a GAP-0083 migration sitting. Preserve BMAD Product Manager.
- **AD-23 / DEC-0436 — Alternative Trading Composition is a complete second system.** ATC is `AlternativeRunConfig` with a complete `PolicyPair` (`AccountingPolicy` + `RiskPolicy`). Admission requires PolicyPair completeness, grants, health, sequential paper-then-live readiness, and L17 human promote before any live `VenueClientKind`. Evidence is QMB JSONL tagged `composition_class: alternative` plus CT-07 lineage to the PolicyPair hash. QMN remains the only `qmf-venue` importer. No new COMP. No dummy CT-22/CT-27/CT-33.
- **AD-24 / DEC-0437 — Invocation envelope and structured grants.** Every public call carries `InvocationEnvelope` (logical invocation/attempt ids, contribution tuple, `instance_id`, `config_revision`, grant snapshot, effect class, idempotency). Idempotency is effect-specific. GrantRecord is immutable after mint; upgrade cannot widen or retarget an existing grant without explicit re-grant that bumps `context_revision`.
- **AD-25 / DEC-0438 — command-owner fencing for sequential deploy.** One command owner per `(account, venue, role)`. Transition states in order: `idle` → `drain-requested` → `draining` → (`residuals-attributed` \| `unknown-blocked`) → `predecessor-acked` → `fenced-activate` → `active` → `retired`. `unknown-blocked` is terminal for the attempt until operator reconcile. Applies to default Book path and to ATC (simulate tokens; venue tokens after paper-then-live + L17).
- **AD-26 / DEC-0439 — durable workflow: outbox, JobHandle parent vocab, join algebra.** Completing predecessor A and making successor B ready is one daemon-sqlite transaction plus outbox. JobHandle reuses QMA AD-17 exactly; never `succeeded` or `awaiting_approval` on a handle. Join algebra follows AD-5 mapping with declared watermark and late/partial policies. No second scheduler.
- **AD-27 / DEC-0440 — application checkpoint manifest, not a second evidence database.** `COMP-QMA-DAEMON` owns a journal-projected `CheckpointManifest` with restore order: QMF rooms → QMB JSONL (including ATC) → QML blobs → artifact bytes → QMA sqlite projections. Missing/corrupt refs become `orphan` and are quarantined; they are never silently merged.
- **AD-28 / DEC-0441 — stream protocol: epoch, cutover, leases.** Subscriptions carry provider `source_id` distinct from optional `venue_id`, epoch, sequence, phase `replay` \| `cutover` \| `live`, and refcounted consumers. A stream subscription is not trading permission. Replay provenance cannot authorize a live command absent an explicit granted policy.
- **AD-29 / DEC-0442 — product-session CAS, reconnect, and change-request completeness.** Mutations are compare-and-set on `expected_revision` with `command_id` dedupe. Reconnect is a query from the client cursor; it never replays unacked intent without the original `command_id`. App-use mints change-request; authoring + operator principal applies; `promote` remains L17 and is not this path.
- **AD-30 / DEC-0443 — package lifecycle, atomic roster, pin/invoke, export oracle.** Pack states: `downloaded` → `installed` → `validated` → `enabled` ⇄ `disabled` → `uninstalled`. Roster publication is atomic. ContributionHit pin stores `(qualified_id, package_version, availability_revision)`; invoke revalidates and never silently resolves to another version. Export scanner is independent of the manifest.
- **AD-31 / DEC-0444 — recipe-definition identity and complete recipe schema.** `RecipeDefinition` identity is `(recipe_def_id, recipe_def_version, recipe_def_hash)`. A run produces a new output release fp1 with CT-07 lineage. Two runs of one definition are two releases, not two recipes. Non-trading outputs need no CT-33/Book/QMN wrap (AD-11 class 3).
- **Umbrella / DEC-0445 — spine adopted in full.** Paradigm is composition over hexagonal libraries and existing application-layer products. ADR-0024 and SCN-0018..SCN-0022 are docs authority only. Implementation authorization remains factory-pipeline-only.
- **Preflight / DEC-0446 — reuse existing applications; no new COMP; no new CT.** Work owners and refused candidates are recorded in the Architecture-preflight verdict section of this ADR.
- **Cheap-veto / DEC-0447 — A1–A6.** Sitting machinery for AD-24..AD-31 is individually overturnable; operator-direct constraints are not. Focused Codex recheck of AD-23..AD-31 returned 2026-09-19 with repairs required (GAP-0092). A1/A3–A6 absorb the corresponding RC field-catalogue findings; they are not operator-spoken schemas.
- **L36 amendment / DEC-0448 — Book/BMS are default implementations, not the ceiling.** L36 stays bot → Book → BMS → operator as the default authority chain. A complete alternative PolicyPair may occupy those roles without dummy records. Human L17 promote, sequential paper-then-live, and QMN as sole venue importer remain.
- **DEC-0389 amendment / DEC-0449 — ContributionHit added; rest of DEC-0389 stands.** Named amendment of the mill/wire two-class freeze only. Do not set DEC-0389 `superseded_by`. Occupancy none; no `hit_class: strats`; no `qml_candidate`; hypotheses stay off the Library facade.
- **Wiring honesty / DEC-0450 — inherit DEC-0286 at `270e992`.** ContributionHit, product_session, durable TaskGraph edges/outbox, Operation descriptor / InvocationEnvelope / GrantRecord, and ATC PolicyPair / AlternativeRunConfig do not exist as wired product surface at that SHA. Do not describe proposed connects as implemented.
- **Dead-list / DEC-0451 — deaths stay dead.** DEC-0084 / 0085 / 0086; DEC-0361 marketplace; DEC-0362 solver; DEC-0366 HMR; DEC-0408..0413 mill deaths. No sixth COMP. No Stage 0 `graph` as workflow executor. No dummy Book. Sensing is not ATC.

## Consequences

Easier: factory units can connect ContributionHit discovery, product-session grants, Graph Template DAG validation, durable Task Graph edges/outbox, InvocationEnvelope/GrantRecord, ATC PolicyPair as a complete second composition, recipe-definition identity, sequential fencing, and pack lifecycle without minting a sixth package or a new contract id.

Harder: every public operation must publish a versioned descriptor and ride an InvocationEnvelope; discovery must distinguish published vs configured vs granted vs reachable vs healthy; Book/BMS variants and ATC PolicyPairs must be complete documents (dummy is CT-04 `invalid input`); product sessions own context under CAS while tabs own nothing; JobHandle vocabulary must stay QMA AD-17; sequential paper-then-live + L17 remain before live venue seats; wiring claims at `270e992` must stay honest (DEC-0450). Public types in this increment (ContributionHit, InvocationEnvelope, GrantRecord, product_session, PolicyPair, fencing records) are specified in prose and CT **usage annotations**; they are not new `schema.fields` and they are not a new CT number (DEC-0446). Factory implementation lands those fields as CT-40 / owner-contract format mints under FEAT-0051..FEAT-0057; until then they remain GAP-0094 / GAP-0096 / GAP-0097.

Foreclosed: a sixth COMP; dummy Book/BMS; treating sensing as ATC; JobHandle states `succeeded` / `awaiting_approval`; Stage 0 `graph` as workflow executor; marketplace / solver / HMR revival; claiming Codex approved AD-23..AD-31; claiming ContributionHit / product_session / durable TaskGraph edges / ATC PolicyPair exist as wired surface at `270e992`; filling GAP-0085 / GAP-0063 / GAP-0061 / GAP-0062 / GAP-0058 / GAP-0081 chrome in this sitting; minting 85 `SCN-*.md` files for the Codex catalog.
