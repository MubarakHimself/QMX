03 · YOUR TOP PRIORITY

The data system — six layers, one direction of flow

L0Ingest — recorderssmall dumb programs that fetch, stamp, and store bytes exactly as received. Calendar one already running. A failed fetch is recorded as failed, never as "nothing happened".
▼
L1Raw evidence — never editedprices · facts (every number with "when we first knew it") · our own execution record, which no one can re-download for us. Corrections are new rows.
▼
L2Processed — disposable by designspread profiles, regime labels, feature tables. Every file names its recipe + raw inputs, so a wrong recipe means delete and rebuild — never argue about copies.
▼
L3The journal — what OUR system didwhat a real portfolio manager keeps: every intent, fill, veto, mode change, MIS snapshot, SQS score, kill-switch event, treasury sweep. Append-only.
▼
L4The research door — splits by defaultagents ask for a NAMED split, never dates. The lazy call returns properly-split data — the easy path IS the correct path. Plain Python can still open any file: the door controls what gets BELIEVED, not what gets read.
▼
L5Backup — a platform featurenightly VPS → workstation, weekly → external drive, monthly encrypted offsite for the irreplaceable megabytes. A restore test on a schedule — an untested backup is a rumour.

The journal's twelve streams

intentstradesvetoesbook eventsMIS snapshotskill-switch auditadapter logtreasurycorrelation ledgercertificatesflagsheartbeat

Everything except MIS snapshots is under a gigabyte a year. The heartbeat stream is what makes "no trades" and "no data" different things — the paper twin keeps beating through every kill-switch fire, so alpha-decay sensing never goes blind.

ArcticDB

NO for v1

Not the licence — that argument was overstated. The real reason: it can only remember when we wrote a number, not when the world revised it. Our two-timestamp rule needs both, and plain Parquet + DuckDB already does it free.

Lineage graph

files now · database maybe never

Your Neo4j instinct is right about the shape — lineage is a growing graph. But we store it as an append-only edge file that plain Python reads; if we ever want Neo4j, that same file loads in unchanged. No lock-in either way.

Auto-detection with your ranges

simple by design

One plain-text rules file you own: pick a measurement from a menu, set your range, say how long it must hold. Flags open and close with memory of why. Hard boundary: flags notify, flags never act — only the kill switch and the Book touch trading.

The sealed shelf

protects you from you

The most recent months of history are never handed to research — by anyone, including you. Unsealing is a separate logged act, once per candidate. It is the strongest defence a one-person operation has against its own iteration bias.

Things that cannot re-happen

A live Tuesday cannot be re-derived, so it carries no recipe fingerprint — it is evidence, filed forever, linked into the lineage graph.

Also settled by the study: a bot is a career — one permanent name plus a fingerprint per revision; variants are new bots linked "variant-of"; a plain-Python bot you promote rides along as an opaque definition. And the bare word "model" is proposed for the banned list — it splits into ML artifact / trading thesis / analysis artifact, which were three different things wearing one word.

05 · REVIEW WITHOUT THE BOTTLENECK

Answer keys — now grounded in real QMX parts

K1

The look-ahead test at registration. One afternoon of work, covers every component any agent ever writes — and it ships with two known-cheaters it must always catch (the broken public SMC library; a "smoothed" regime model), which proves the test itself is awake.

K2

Two reference calculators for every indicator. TA-Lib and talipp answer independently; QMF must match both, and warm-up is computed, not guessed. Kills the "backtest says buy, live says hold" bug class — the most expensive one there is.

K3

One venue checklist run against both the practice venue and a real demo account. Doubles as the only way to learn the broker facts written in no document. (Full catalog: nine module families, each with its external truth — including your pair-scoped kill switch tested against our own recorded calendar weeks.)

Honest gaps where no external truth exists yet: the fill model (only measured live slippage can calibrate it — waits for the tick recorder, flagged to the backtesting session); what a "correct" zone even is (no canonical definition anywhere — your GitBook definition becomes the only spec); and the Book schema must first be extracted from GitBook into machine-checkable form — operator-verified work, not an agent guess.
