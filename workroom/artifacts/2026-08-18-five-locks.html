The locks, in plain words
1≈2 sessions

The Dictionary

= qmf-core, needs your yes

What an Order, a Fill, a Position, a Tick is — exact money (no rounding errors), exact time (one world clock), and the label every stored result carries so it can never lie about what produced it. This is the language everything else speaks.

Six choices get frozen inside this lock. Each is cheap to decide now and ruinously expensive to change later, because changing any one invalidates every test result ever stored:

  • One world clock, measured to the nanosecond.
  • What counts as "the same instrument" — the venue plus its symbol.
  • Whose indicator math is the reference answer (proposal: TA-Lib, the industry standard).
  • Three honesty levels stamped on every backtest — did it look at bar closes, inside bars, or every tick.
  • The bar a strategy must clear to count as good — this number also sets how many attempts your data can honestly support.
  • The full label on every result: which bot + which data + which Book + which version of everything.

What slides after it: every module becomes a function over these words. Modules stop needing to agree with each other — they already agree by speaking the same language.

3≈300 lines

One ID Card

Every thing in the system — a level, a trigger, a bot, a Book, a model, an experiment — carries the same small ID card: what it is, its version, its fingerprint, its lineage. Promotion toward live is an update on the card, never a file moved. Nothing is ever deleted; retired things keep their history.

What slides after it: build the card format once, and seven different needs are served for free — versioning, dedup (two agents "discovering" the same bot get the same fingerprint), honest attempt-counting, audit, rollback. This also already covers most of what the DeepSeek harness does — which is why the fancy extension plumbing can wait for the agentic era.

4≈1 session

The Agent Page

The one printed page a future agent reads to build things with QMF: the forms for a Level, a Trigger, a Confirmation, a Confluence, a Book config. Guidelines, not walls — agents still have all of Python beside it. But what gets registered comes through these forms, so it's uniform.

What slides after it: the agentic system becomes a consumer of QMF instead of a redesign of it. The five research papers become downstream reading, not an upstream blocker.

5≈1 session

The Answer Keys

For each module, name the external thing that proves it right: a reference library for indicator math, a live demo account for fills, deliberately-overfit fake strategies that the lie detector must catch, a look-ahead test no component can register without passing.

What slides after it: this is the only lock that raises your speed limit. Right now the factory's ceiling is your review evenings. Named answer keys turn "Mubarak checks it" into "a machine gate checks it" — and that is what actually makes a one-person operation scale.

The two things I used jargon for — in plain words

"Full statistics battery" = the lie detector

Math that catches a strategy that only looks profitable because thousands of variants were tried until one got lucky. Try a million worthless bots and the best will look brilliant — the lie detector knows how lucky "lucky" is.

My call: keep the cheap part now — a counter that records every attempt ever made (agents can burn years of statistical budget in an afternoon). Defer the full lab-grade machinery until one strategy actually gets far enough to need interrogating.

"Program / Campaign" = the challenge rehearsal machine

A machine that plays a prop-firm challenge start-to-finish — evaluation, funded, payout — then replays it a thousand times and tells you your pass rate and which rule kills you.

My call: genuinely valuable — but it's prop-firm machinery, and you ruled prop-firm Books into the agentic era. Keep only the generic slot for firm rules (cheap, shapes the money gate); build the rehearsal machine when its era comes.
