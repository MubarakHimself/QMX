- paragraph: "DESKTOP interfaces only. Investigate whole agent working environments, especially Manus, Factory, ChatGPT and Claude: session/project navigation, substantial conversation, browser/files/code/tools alongside it, open-work tabs and expandable work areas. The design question is a desktop application host: a compact global menu opens a complete work environment in a tab; its interior can have its own navigation and tools. The agent environment is one such interior, and agents can also participate in other environments. Find full-screen working layouts that help distinguish global navigation, local session navigation and active work. Also compare Bloomberg-style trading terminals and CRM/CMS multi-module shells for the outer host. Do not return mobile, isolated component examples, landing pages, generic KPI dashboards, or arbitrary sidebar-plus-chat mockups. Clearly identify whether each screenshot supports the outer host or the inner agent environment. Prioritize Manus and distinctly different desktop agent layouts."
