# PRD discovery — the three architecture sittings

## Platform shape (the three sittings, one platform)

- **QMX** = the whole platform (the product the operator is building).
- **QMF** = the framework: one repo, a uv workspace of **seven installable packages** importing as `qmf.*` (`qmf-core`, `qmf-registry`, `qmf-data`, `qmf-indicators`, `qmf-structure`, `qmf-venue`, `qmf-risk`), plus calendar/indicator/structure **extensions outside the roster**. `qmf-core` is a zero-dependency definitions-only hub; everything else depends inward on it. QMF is a library, never an application.
- **QMB** = the QMX experimentation/backtesting product: one library + the `qmb` CLI + doors (Python API now, MCP later). Built ON QMF; never a QMF roster package.
- **QML** = the QMX bot-authoring library: one `qml` distribution (`import qml`). Built ON QMF; authors the Bot artifacts and gates their registration.
- **Standing principle:** everything downstream of QMF — trading node, backtesting (QMB), bot authoring (QML), agentic system, QMX UI/Simulator — is BUILT WITH QMF libraries. Applications are out of QMF's own scope.
- **Authority order (constitutional, verbatim across all corpus layers):** *bots trade; books control bots; BMS accounts for and constrains books; nothing above a bot touches the market — bot → book → BMS → operator.* Nothing may invert or shortcut it.

## SESSION 1 — QMF V1 Foundation (2026-08-19/20, folder "architecture-QMX-2026-08-19", AD-1..AD-41)

Design paradigm: **Contract-hub library workspace (hexagonal at workspace scale).** `qmf-core` carries only definitions (exact value types, domain nouns, typed refusals, fingerprints, protocols); runtime concerns enter through protocols outer packages/extensions implement. Node runtime behaviour (doors, ledgers, counters, trigger matrices, kill-switch firing) is deliberately EXCLUDED — QMF carries contracts and seams only.

### Spine invariants a PRD must respect (AD-1..AD-41)

**Build substrate & toolchain**
- **AD-1** CPython **3.14** pinned everywhere. Tier-1 OS targets: Windows 11 x86-64 + Ubuntu LTS x86-64 (Ubuntu untested until a remote exists). Pure-Python, OS-neutral.
- **AD-2** One repo, uv workspace, seven packages, PEP-420 namespace (**no `qmf/__init__.py` ever**), `src/` layout, one committed `uv.lock`, **lockstep** roster versioning; extensions on their own SemVer ladder outside lockstep; discovery = explicit registration at the composition root, never ambient scanning. Shared nouns defined in `qmf-core`, records owned by `qmf-registry`.
- **AD-3** Toolchain: ruff + pyright-strict + pytest; per-package coverage floor 80%, 100% branch on CT-01/CT-02 primitives; every package ships executable tests AND reference usage (L27). Strictness governs QMF's own source; consumers are never forced into it ("don't-box-in").
- **AD-4** Three quality tiers bound to factory events (tier1 `poe check`; tier2 `poe check-integration` + contract tests in isolated per-package envs; tier3 `poe check-release` + build + clean-install smoke on both OSes). Host-neutral until a remote exists.
- **AD-5** Two version ladders: package SemVer (lockstep, 0.x until V1 ships, one-release deprecation window) + **per-contract integer format versions stamped into every artifact**; a format version's meaning never mutates — incompatible change mints the next version + migration note. History is append-only and forever-readable; QMF never loses the ability to read old evidence.
- **AD-6** Dependency/licence tiers: permissive (MIT/BSD/Apache/PSF) free; LGPL only unmodified+separate; GPL/AGPL prohibited; strategy-family and platform-imposing (own loop/runtime/data-model) deps prohibited; `qmf-core` = **zero outside deps**; every dep registered in `DEPENDENCIES.md`.

**Core value laws (money, time, identity, refusals, worlds)**
- **AD-7** Exact money: Money/Price/Quantity are integer counts at a declared scale; **binary float banned on the money path** (a taint, not a location), crossed only at named conversion boundaries with a declared rounding mode; foreign money/floats stored verbatim as evidence, never identity; exact-rational parameters; pinned canonical numeric form for identity.
- **AD-8** Exact time: int64 UTC ns (POSIX, 1677–2262, checked); CivilDate/TradingDate distinct types with calendar identity in-band; wall vs monotonic clocks type-separated; Clock is a core protocol injected at the composition root (replay clock too) — **nothing below the root reads the system clock**; forex market-hours calendar ships first (17:00 America/New_York rollover, QMX's own accounting rule); tzdata pinned in extensions, participates in fingerprints; three calendar kinds named apart (market-hours / day-boundary / news).
- **AD-9** Identity: instrument = (venue, opaque symbol) never parsed; VenueId operator-minted, opaque, stable (a white-label broker is its own venue); **broker identity is deployment configuration, never architecture** — no rule may name a specific broker; Venue and Account are first-class nouns; accounts carry roles (live/demo/paper-validation/paper-benched/prop-firm); Books bind to accounts.
- **AD-10** Deterministic fingerprints: the `fp1` recipe (UTF-8 JSON, sorted keys, NFC, integer-only identity numerics, no null, order-significant arrays, SHA-256, emitted `fp1:sha256:<hex>`), one implementation in `qmf-core`; every field identity by default, display-only exclusion is an explicit versioned declaration; idempotent re-writes accepted, true collisions refused+alarmed.
- **AD-11** Typed refusals: seven categories (invalid input / unsupported capability / unavailable dependency / stale evidence / policy rejection / transient venue failure / storage failure), machine-readable context + retryability; **returned as result unions, never raised across a package boundary**; value construction = unchecked constructor + validating `try_create`.
- **AD-12** Result label + worlds: five identity parts (producer contract identity+format version, input fingerprints, evidence time range, computation identity, evidence class, world). Worlds: **`live`** (paper/demo included via account role), **`replay`** (data-driven injected clock, usable today), **`simulated`** (reserved-UNUSABLE in V1 until backtesting defines simulated-time typing). Non-live world never writes the live namespace; namespaces are role-scoped; factory-sandbox artifacts carry `provenance = sandbox`.
- **AD-13** Measure-then-budget: **no invented performance numbers**; every component ships a benchmark harness (speed + peak memory) at framework-native load ladders (~40-bot scenario with 10/100/200 marks sizes the ladder); first measurements = fingerprinted (OS, CPU-class)-scoped baselines gating tier-2; one design constraint stated now: `qmf-core` imports in well under one second.
- **AD-14** Loud failure, traceable behaviour: refusals never swallowed; structured logging with `correlation_id` across every boundary; every stateful component exposes `health()`; logs ≠ journals (logs are ISO-8601 Z display; journals store int64 ns + writer + sequence); signals exportable to standard monitoring stacks.
- **AD-15** Concurrency: QMF values immutable; pure libraries stay pure; stateful components own external resources under one-writer-per-stream; **QMF never spawns threads/background work — the application owns all concurrency**; async only at the venue network edge.

**Registry, data, storage, splits**
- **AD-16** Registry records + lineage: per-kind versioned schemas + a tiny common header; stable id derived from `fp1`; lineage after birth lives ONLY in append-only typed edge records (pinned JSONL); kinds addable never redefined; **no database server**; risk-sitting kinds + edges minted here (`continues-performance` vs `carries-ledger`, `enacts`, `branches-from`; `supersedes` is linear).
- **AD-17** Multiplicity at every layer: a Bot contains one-or-more confluences; confluences contain one-or-more levels/triggers/confirmations; no bot-vocabulary layer hardcodes "exactly one"; composites are own artifacts with lineage; Bot identity is content, binding is a separate dated record (one Bot at exactly one Book at a time; re-binding never mints a new Bot).
- **AD-18** Promotion record skeleton: reserved promotion-occurrence card; human-only signer; mandatory plain-words summary is an identity field; V1 "signing" = operator's recorded approval attesting the `fp1` (no crypto dep); the gate itself is platform territory.
- **AD-19** Data rooms + bitemporal law: seven room-roles (ingest / immutable raw archive / processed / journal / split-governed research door / backup / registry room) **instantiated per world**; cross-world reads refuse; stores Parquet/DuckDB/SQLite/JSONL each behind a QMF-owned contract; no DB server; only raw-archive + journal are evidence-bearing; every external fact carries event-time/known-at/source/revision; corrections append never overwrite.
- **AD-20** Migrations/retention/backup: preflight → backup-first → dry-run → migrate → verify; never in-place mutation of the only copy; raw + lineage kept forever; backup design ratified (nightly, encrypted, versioned, off-machine) but **schedule/execution/cutover are application/ops-owned**; QMF ships backup/restore/verify primitives only.
- **AD-21** Splits/journal/doors: fingerprinted, time-ordered, non-overlapping split manifests each pinning one calendar identity in-band; **12-month seal = a no-peek lock enforced now as a policy-rejection refusal at every read boundary**; journal = N per-writer streams recording **seven event types** (decision, order, fill, risk transition, promotion, data quality, control action); `correlation_id` excluded from identity; source adapters keyed on (source, source-native id, revision).

**Indicators & structure**
- **AD-22** Indicator protocol + series vocabulary: `Bar`/`Tick`/`Quote`/`BarSpec`/exact-rational live in `qmf-core`; **`BarSpec` replaces the bare word "timeframe"**; identity = the entire declared configuration; outputs full-length, index-aligned, presence-mapped (NaN/sentinels banned), carry knowable-at; warm-up = integer count in the input's own sample unit; two conformant modes (batch + streaming) held equal by a tier-2 equality law; custom indicators authorable in plain Python outside governed evidence, graduate via the extension path.
- **AD-23** Canonical arithmetic: **TA-Lib 0.7.1 (C + wrapper) is the pinned reference** (wrap-not-reimplement where it implements a formula; QMX implementation canonical where it doesn't); pinned as lockfile artifact hashes + an identity-bearing reference-configuration record asserted at import; upgrades gated, output change mints a per-configured-indicator format version.
- **AD-24** Light vs heavy: budget-declared + benchmark-proven (per-update cost, bounded state, bounded/anchored window, synchronous availability); **heavy by default until the live-path rung has a baseline**; verdict is machine-scoped display-only, never identity; heavy runs off the trading path through the same contracts.
- **AD-25** Causal structure lifecycle: a family is a TYPE OF CHART OBJECT (never a strategy/school); objects minted once at observation with anchor span + observed-at (known-at); confirmation/invalidation/interaction are append-only edges; current state = read-time fold; precise-rule bar ("confirmed the moment X happens, X knowable then"); evidence class (confirmed/unconfirmed/provisional) is identity-bearing; the emission invariant is the interim look-ahead guard; no privileged families (operator-authored families are first-class peers).

**Venue (module — nothing imports it)**
- **AD-26** Venue secret lifecycle: components handle typed `SecretRef`, never values; opaque minted reference ids; `SecretValue` never renders; a tier-1 secret scan; the connection manager is the single component permitted to hold values in memory (injected `SecretStore` port); one live refresher per credential; store-before-discard rotation; documented tested compromise drill; **factory sandboxes never hold live secrets**; credential-management UI is platform territory.
- **AD-27** Venue commands + the uncertainty law: command stream = (VenueId, account); command vocabulary is exactly **five typed kinds** (place_order, cancel_order, close_position, close_all, amend_protection) — no free-form payload, addable never redefined; **four-outcome law** (accepted-by-venue / rejected-by-venue / denied-locally / UNKNOWN) — a timeout is a state, never a rejection; recording precedes interpretation; order state is a read-time fold; **command retry is prohibited**; reconciliation verdicts (reconciled/drift/unknown/out-of-lookback) gate the command pipe only — sensing never blocks; fail-closed on outage.
- **AD-28** Venue adapter contract + capability discovery: one neutral port, four contracts (CT-18 capability / CT-19 command / CT-20 event+reconciliation / CT-21 secret-session), implemented per venue, wired by the composition root via injected sinks — **no new dependency edge**; capability surface splits into a static declaration + a per-account measured venue-observation profile; **verify-or-refuse throughout** (a measured daily-bar boundary mints a venue-scoped market-hours calendar identity); a CCXT-class crypto venue slots in later through the same port. cTrader is adapter #1 but **no rule hardcodes a broker**.

**Risk (module — nothing imports it; QMF carries contracts/seams, node carries runtime)**
- **AD-29** Book/BMS/binding chain: **BMS is the account-facing supervising layer — one BMS per account, serving many Books; a Book binds exactly one BMS at a time; a Bot binds exactly one Book**; a crypto/prop-firm BMS is a new BMS version, never a second stacked BMS; three identities minted apart (Book version fp1 / Book instance / binding epoch); the risk domain is the binding tuple aligned with the (VenueId, account) command stream; `world` is constant `live` for every V1 binding (a replay mints a different binding, incomparable by design); recommended default is one Book per netted account.
- **AD-30** Templates as configuration artifacts + git-logic versioning: a Book/BMS template is a JSON-Schema-class structured artifact; every variable carries unit + exact-rational value + **`ui-editable | uneditable` flag** ("configurable" = UI-editable at platform level) + `admission_impact`; numbers live inline and are identity-bearing; versioning = append-only `branches-from` graph, "current" = a dated pointer, UI edits mint a version never mutate; declared sections named (`charter`, `footprint_requirements`, `money_rules`, `admission_bar`, `leash_grammar`, `capacity_and_sweep`, `exit_policy`, `control_policy`, `protection_windows`, `paper`); deferred-contract slots ship as `pending(<gap>)` that pass registration and block live binding.
- **AD-31** Risk record kinds + per-entity journals: Book/BMS/per-bot journals are **read-time PROJECTIONS** over writer-scoped streams (an entity is not a writer — flagged as the distiller's substitution for the operator's per-entity-stream request, overturnable); paper/live separated by construction; the venue join is pinned CT-25 surface.
- **AD-32** Book/BMS admission — three technical layers, no probation ever: Layer-1 linters (at registration), Layer-2 technical shakedown (demo/paper), Layer-3 one operator signature; **no trial period/probation/paper-performance gate exists**; `admission_bar` = a SET of named requirements (no composite score) with thresholds as a discriminated union that may be `not-yet-ruled`; **blank blocks live money** (registers + binds non-live freely; live binding refuses); no paper role may gate live money.
- **AD-33** Exit ownership: **the Book owns exit policy** for the life of a position; a Bot may PROPOSE risk-monotonic exits (close_full, tighten_protective_stop — direction+bound, never a price) through CT-23; **`requested_r` is Book-resolved, never bot-supplied**; the protective stop is Book-owned and venue-resident where CT-18 declares attachment; `ExitLogicRef` per family; a zero-bot-intent static-stop-only Book is the honest V1 default; **`close_partial` is not a V1 kind — partial exits refuse**; every close carries a typed close reason; whole-trade attribution credits the opening Bot.
- **AD-34** `amend_protection` = the fifth venue command: risk-non-increasing, **never emulated by cancel-then-place**; amend atomicity is UNDOCUMENTED → verify-or-refuse (single-sided the only legal V1 path); venue-managed trailing is a declared capability, never assumed; **V1 dynamic SL/TP = the move-to-breakeven ratchet only**, its trigger/offset configurable UI-editable with no spine value.
- **AD-35** Paper mode: paper is a **Book-level mode** (LIVE | PAPER), a dated execution-binding change — a standing evidence state, not a waiting room; **no Bot twins ever**; every trigger declares routes-to-paper | blocks-paper (market-risk controls block paper too; capital/authority controls route to paper); one active paper-routing target per binding; per-intent `execution_target` resolved once at intent mint (one intent can never fire twice); **paper money is frozen evidence — configurable UI-editable starting balance, never hand-adjusted; a reset mints an operator-signed paper epoch**; paper P&L never becomes Treasury cash and never buys a seat; decay comparison is R-denominated under a declared `cohort_key`.
- **AD-36** Control actions (kill switch, kill line, flatten authority): **kill switch** = global black-swan authority (stops all NEW trading incl. paper; sensor-fed; escalates automatically, de-escalates only by a human; effect chosen by node severity policy) vs **kill line** = per-Book capital floor (auto-flattens that binding's scope, stands the Book down); named apart, never merged; the **exit-preservation invariant** (no control may ever block a risk-reducing act or the recording of evidence — blocking is entries-only); flatten authority assigned (operator always; Book policy only via pre-declared triggers; protection authority where node severity policy declares it; nobody else); standing protection intent journaled before dispatch, re-decided not retried, never time-expires; veto accounting + suppression accounting are first-class CT-32 evidence.
- **AD-37** Same-tick priority: per (VenueId, account) stream, one arbitration point; ranks 0 operator > 1 protection (kill-switch class) > 2 BMS/Book forced flats > 3 fast invalidation > 4 ordinary bot exits/amendments; ranks BMS-declared per stream, mandatory, unique; a contradicting Book refuses at bind time; cross-stream ordering is a declared non-guarantee; a higher rank may never reduce protection a lower rank would deliver.
- **AD-38** Protection windows (news / daily_dead_zone / session_handover_buffer): one control-window contract; kinds a Book enables, calendar-derived, absent for 24/7 markets; a window is two instants (never an offset); **blocks new entries on in-scope instruments — live AND paper alike — and nothing else** (never an exit/protection/recording); instrument scope resolves through dated per-instrument currency-exposure records (symbol parsing prohibited); widen-never-shrink forward-only; fail-closed, no live skip button; **all widths/anchors/buffers are configurable UI-editable variables with NO spine value** (disagreeing dead-zone evidence recorded unmerged; ±15min news buffer withdrawn).
- **AD-39** Spread Quality Sensor (SQS) V1: a CT-16 configured producer; V1 formula = historical average spread for the session window ÷ current live spread (exact rational over two scaled-integer spreads; ≥ threshold passes, strictly below blocks); mechanism (per-class threshold, hysteresis band, outlier guard, conservative sentinel); **every parameter configurable UI-editable with no spine value**; authority boundary — the sensor computes, the transport carries, **the Book door decides**; V1 blocks only, never shrinks size; a live binding requires a present baseline artifact.
- **AD-40** R, numeraire, capital, dimensional law: **R is one relationship with three typed faces** (original_risk_distance / original_risk_amount / r_multiple), **frozen at admission**; every position declares its planned full-loss price before it opens (else admission refuses) — "a strategy with no planned loss point cannot trade in QMX"; **numeraire is USD system-wide in V1** (non-USD binding refuses until a rate source is ratified; the conversion seam ships switched-off); V1 admits no scale-in; three capital concepts typed apart (roster state / risk allocation / capital); the **dimensional law** — a closed unit-kind vocabulary (incl. minted `value-factor`), every variable + formula unit-typed with a symbolic checker, every formula ships an executable worked example; FORM-0006 stays dead as the suite's permanent negative test; **margin sizing decided-deferred** (V1 does not size by margin).
- **AD-41** Stop-out, bench counter, performance evidence: the bare word "stop-out" is banned (venue margin liquidation = `venue_liquidation`; the breaker's input = `qualifying_loss_exit`, a close with `realized_r ≤ −q`, `q` a UI-editable per-family variable ~1R); the exit record (CT-29) is one per virtual-position close; the bench counter is a **read-time fold** over exit records (crash-proof, bounded by binding epoch); seat state `active | benched`; the **performance-result container (CT-32)** serves both admission-bar evidence and analyst report (declared population/period, unit-kinded measures, suppression + veto accounting); **alpha decay ships as evidence primitives only — the math is deferred, the collection starts now**; measurement publishes, never acts.

### Cross-cutting rules the PRD inherits
- Dependency direction (default-deny): `qmf-core` depends on nothing; every package may depend on `qmf-core`; **nothing imports `qmf-venue` or `qmf-risk`**; the only ratified inter-library edge is `qmf-registry → qmf-data`; adding an edge is a spine amendment.
- Clock injection seam: no component below the composition root reads the system clock.
- Every configurable variable declares `ui-editable | uneditable` and carries a unit-kind; runtime state is always a read-time fold over append-only records, never a stored mutable field.
- No shipped mock market data, fake Bots, or default strategies; synthetic data stresses infrastructure, never validates edge (L6/L20).

### QMF explicit OUT-OF-SCOPE / node-territory (from the spine's Deferred table)
- Look-ahead **registration gate** + attempt counter (GAP-0016/0017) — deferred to backtesting; consequence accepted (artifacts registered before then carry no causality evidence).
- **Node runtime behaviour**: kill-switch trigger→level→effect matrix, the level state machine, Book/BMS runtime (doors, ledgers, counters, trigger firing, evaluation of the sizing ladder), MIS consumer boundary, pool/retry/health constants — all node authority (do-not-default; corpus numbers are reconfirm-grade only).
- Margin-aware sizing + admission-time free-margin check (node sitting; V1 does not size by margin).
- Cross-currency conversion + multi-currency unlock (numeraire USD in V1; non-USD refuses until a rate source is ratified).
- Prop-firm extension (Books, a prop BMS variant, daily-loss/trailing-drawdown) — socketed, no firm modelled in V1.
- Backtesting content (GAP-0048), simulated-time typing, SR*/search-quality threshold (GAP-0049).
- L2 depth / footprint / order-book series vocabulary — ungoverned research lane until a later pass.
- News-calendar auto-sync/UI/cron; full observability/monitoring design; deployment topology/infra/ops envelope; crypto calendar + crypto design pass — all later/node/ops territory.
- Numeric latency/performance budgets — await first measured baselines.
- General `amend_order` (price/size/expiry) and partial-close semantics — explicit later mint; until then partial exit refuses.

## SESSION 2 — QMB (2026-08-20, B-1..B-15) — the experimentation/backtesting product

Design paradigm: **Hexagonal with config-composition — "one tunnel, many wirings."** A pure library (the wind tunnel) exposes ports (clock, data feed, fill, cost, financing, sampler, registry-read); every run binds adapters from **one resolved read-only run-config artifact**; exactly one impure **orchestrator** performs all writes and process management; thin doors (CLI first, Python API, MCP later) carry no domain logic. Vocabulary law: QMB is a **library** and a **CLI**, never an "engine" or "kernel". QMF spine AD-1..41 binds in full, read-only.

### Spine invariants a PRD must respect (B-1..B-15)
- **B-1** One library, thin doors; the CLI is the product face; every capability exists once in the library as a pure function; door parity enforced by a tier-2 contract test; UI backend consumes the Python API in-process; MCP is a sibling door shipped after CLI v1, localhost-bound.
- **B-2** Event-slice run loop with an injected frontier clock; **one loop** (backtest/replay/live differ only by which clock+adapters the config binds — never forked); pinned identity-bearing sub-phase order; higher-BarSpec bars emitted only on completed boundaries (a forming bar is never actionable); warm-up in-loop, trading-locked; **simulated-clock typing refused until GAP-0048**.
- **B-3** One resolved run-config artifact per run (the config compiler): layered precedence (flags > run spec > BMS fragment > Book fragment > workspace defaults); Book/BMS fragments occupy DISJOINT key namespaces (collision = compile-time refusal; sanctioned overlap → BMS outranks Book); the resolved artifact cites Book/BMS/binding by **`fp1`, never `name@version`**; its fingerprint is the run id root + ledger key; every QMB run mints one `world=replay` binding.
- **B-4** Pure runs return values; the orchestrator writes logs + exactly ONE ledger line (aborted included); the **bar verdict is reader-derived, never frozen** (one read-time fold per requirement against the cited AD-32 bar); a replay-world verdict can never gate live money; ledger is WriterId-scoped fragment files merged in a world-and-role-scoped read view.
- **B-5** Process-per-run concurrency with a resource governor (`min(cpu, ram)`, enqueue-on-full); every run cancellable with declared time/memory limits; **12–14 concurrent runs is a motivating reference, not a validated budget**; no Ray, no required Docker, no daemon.
- **B-6** Pluggable fill/slippage/cost/financing ports with declared calibrated fidelity; inbound path is a CT-23 Book-resolved intent; financing is a scheduled position-level event; fidelity identity = adapter-id + composition-version + taint; **lowest fidelity wins per run**; all fills carry an `optimistic` taint until GAP-0048 (such runs spend no split budget, claim no edge); the forex solve is **CALIBRATION, never invention**, from QMX's own recorded evidence per broker.
- **B-7** Provenance-derived world (never caller-declared); store-persisted fabricated data = `world=simulated` (policy rejection for governed evidence until GAP-0048); procedure-ephemeral perturbation stays `world=replay` (robustness-only); L20 stands.
- **B-8** Declared parameter spaces + pure generation-stepped adaptive (TPE-class) search; sampler is a pure function evaluated by the orchestrator between spawns (never an in-process study/daemon); every trial is a first-class ledgered run (`role=trial`); ships anti-overfit sensitivity analysis; train/test = split-manifest fingerprints.
- **B-9** Research surface = the same library's pure functions, uv-portable (no server/Docker); the operator's workstation is a controlled-room host; sealed/governed evidence never leaves controlled rooms.
- **B-10** One canonical result artifact = **a CT-32 performance-result** (chart series + trade-event refs = declared QMB extensions); all rendering is a pure downstream function; agents read the artifact, never renderings; re-running a run id reproduces the CT-32 fingerprint.
- **B-11** Data commands are thin fronts over qmf-data contracts; **download-once under the user's own provider relationship** (Dukascopy primary; dukascopy-node the acquisition-tool reference) into the immutable raw archive; runs never fetch from providers; every ingested window records a license tag.
- **B-12** Declarative stream sets; sweeps are Cartesian batches of isolated fully-labelled runs; at most one open position per (venue, instrument); one settlement asset per run.
- **B-13** Versioned uv/pip-installable package (library + CLI in one wheel); **`uv add qmb` is the primary channel** (Python API must be importable); `uvx`/`uv tool` is CLI-only convenience, never the sandbox channel; QMB + QMF SemVer ride as display-only provenance, never identity.
- **B-14** The validation ladder ships as library functions (backtest, optimize, Monte Carlo, rule-significance, walk-forward), each an exact statistical procedure versioned as a contract; a bounded AD-7 float carve-out for return-space statistics; thresholds deferred (GAP-0048/0049), mechanics do not wait.
- **B-15** Registry delivery: one library-owned registry-read port; state reaches a machine as an immutable fingerprinted **as-of set** delivered by a **passive file-sync hub** (dumb storage, not a service — DEC-0084 central-service stays dead); a sweep freezes one as-of at batch admission; stale-evidence refusal.

### QMB naming/vocabulary settled
- **QMB** IS the glossary's "future backtesting library" entry; the **Simulator** stays a separate deferred UI product that will consume QMB. Command = `qmb` (supersedes the earlier `qmx` command name). "**Experimentation**" is the umbrella activity, "**backtest**" the verification stage (rename SETTLED). Banned: engine, kernel, exam, plugins (for QMB parts), fake counterparty, snapshot (say "as-of set").

### QMB explicit OUT-OF-SCOPE (Deferred fence)
- GAP-0048 fidelity taxonomy VALUES + forex calibration content + parity contracts + simulated-time typing (B-6/B-7 hold the seams).

## SESSION 3 — QML (2026-08-21, QL-1..QL-10) — the bot-authoring library

Design paradigm: **Declaration-plus-logic authoring.** A governed bot is exactly **two artifacts** — a **declaration** (a structured config artifact under AD-30 discipline, registered as the CT-33 Bot definition) + **logic** (plain Python conforming to QML's runtime protocol, a versioned distribution whose identity enters the Bot's identity). QML authors both and gates their registration; QMF governs; hosts execute. QMF AD-1..41 and QMB B-1..15 bind in full, read-only. Ran autonomously by operator delegation; every without-operator call is tagged and individually overturnable.

### Spine invariants a PRD must respect (QL-1..QL-10)
