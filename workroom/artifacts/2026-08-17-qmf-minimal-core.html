2 · The first brick

Library #1: qmf-core — the language

Everything every hat will ever import. No loop, no broker, no backtest, no downloads — pure definitions.

  • exact money — prices, quantities, balances as exact decimals. A float rounding error in money is a bug that compounds silently; banned at the type level.
  • exact time — one instant type (UTC, nanosecond), plus "which trading day is this" for sessions and rollover, plus the two-dates stamp: when a fact happened and when it became knowable.
  • the nouns — Instrument, Bar, Tick, Order, Fill, Position, Account — style-agnostic (5-minute scalp to month-long hold) AND seeded for order flow now: DOM / depth-of-market, tape (time & sales), level 2/3 data, market-structure primitives — so crypto's rich order books never force a rebuild. Forex gets sessions (per-pair, a bot may trade several); crypto is 24/7 — the line drawn explicitly.
  • typed refusals — every "no" carries a machine-readable name PLUS a human-readable explanation — this codebase is written for agents and for you.
  • the stamp machine — canonical writing-down + fingerprinting of any definition, so recipes, versions, and results can be identified exactly. (Used later by confluences; built now because everything needs it.)
  • versioning discipline — definitions carry versions from birth; changing a definition mints a new version instead of silently rewriting the old one.
